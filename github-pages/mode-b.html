Install on a new MacBook
1
Get your device token
Go to My MacBooks tab → Add a MacBook → copy the generated token.
2
Run the installer
On the new MacBook, open Terminal and run:
curl -fsSL https://YOUR_ORG.github.io/promptshield/install.sh | bash
Takes ~60 seconds. Installs CLI + Cursor rules + Claude Code hooks + CLAUDE.md sync.
3
Paste your token when prompted
The installer asks for your PromptShield token. Paste the one from Step 1.
4
Done — all features active
DevGuard validates every prompt. CLAUDE.md syncs automatically. Usage tracked on this dashboard.
Claude Max mode (no gateway)
⚠Claude Max mode runs DevGuard locally — no tokens sent through the gateway. Requires ANTHROPIC_API_KEY set in your environment for prompt rewriting.
1
Install normally
Run the installer above. When asked for mode, select --mode max.
curl -fsSL .../install.sh | bash -s -- --mode max
2
Add API key to environment
The rewriter calls Haiku directly for prompt improvement:
echo 'export ANTHROPIC_API_KEY=sk-ant-...' >> ~/.zshrc
3
Sync CLAUDE.md manually
~/.devguard/bin/claude-md-sync.js
Verify installation
Run these on the MacBook to confirm everything works:
team-claude status
cat ~/.devguard/CLAUDE.md | head -5
node ~/.devguard/bin/pre-tool-hook.js <<< '{"prompt":"test"}'
